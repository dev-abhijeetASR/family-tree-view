📌 Points to remember

Points to remember while editing

  1. Select a person by clicking the name. Double-click (or F2) to rename — Enter saves, Esc cancels.
  2. Renaming shows two boxes: Hindi and English. The second one fills itself in — check its spelling before pressing Enter.
  3. Hover over a name for quick buttons: + Child, + Sibling, + Parent, Rename, Remove.
  4. A generation missing? Select the person just below the gap and use + Parent. Never type numbers into names — the generation numbers update by themselves.
  5. Remove takes out only that person; their children move up to the parent. To delete a whole branch use Shift+Delete (it asks first).
  6. To move someone under a different father, drag the name onto the new father (drop on the top or bottom edge of a name to place beside it).
  7. Many names repeat in different families. Check the generation number and the path shown at the bottom before changing someone.
  8. Made a mistake? Ctrl+Z undoes, Ctrl+Y redoes.
  9. Changes save automatically, but only in this browser on this computer. Use Export JSON regularly as a backup; Import brings it back.
  10. Reset to original throws away every edit and goes back to the copy from the phone — only if you are sure (Ctrl+Z still works right after).
  11. Colours come automatically from the family branch, and orange is reserved for “my line”. A colour swatch gives someone a custom colour; Auto removes it.
  12. ★ marks “me”. Set as me moves it to the selected person, ★ Me jumps to it, My line fades everyone else.
  13. Columns (C) puts each generation in its own column with a Gen ruler on top — handy to see who belongs to the same generation.
  14. Details (I, or ⓘ in the hover buttons) keeps birth / death year, village, notes and a photo for the selected person. Years appear next to the name; photos are shrunk automatically and saved with the map.
  15. Relation (R): select the first person, press Relation, then click the second person. The path between them lights up and the relation is named (e.g. “2nd cousin, once removed”). Esc clears it.
  16. Stats shows people per generation and the largest families — click a name to jump there.
  17. Save / Export makes a picture (PNG, for WhatsApp), a poster file (SVG) or Print → Save as PDF. It saves what is open on screen, so press Expand all first for the whole tree.
  18. On a phone or tablet: pinch to zoom, drag to pan, tap a name for the buttons, double-tap to rename.
  19. Keys: L हिंदी/English · G generation numbers · + / − zoom · Ctrl+F search (Enter = next match) · C columns · I details · R relation · Tab add child · Shift+Tab add parent.
